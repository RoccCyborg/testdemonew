Career Assessment Tests

Reusable diagnostic assessment system · Select a test, enter the candidate name, and generate an individual report.

Available Tests

Each test is independent and can be reused for multiple candidates. Scores and saved progress are separated by test ID.

Test 01 — Job Readiness Assessment

Computer fundamentals, MS Word, Excel, PowerPoint, digital work, communication and workplace behaviour.

Foundation assessment for office, customer support, operations, telecalling and related entry-level roles.

Test 02 — Office / Admin Skills

Data entry, document management, file naming, record keeping, correspondence, scheduling, inventory, invoices, employee/attendance records, Excel MIS, reporting, email, scanning and printing.

Office Assistant · Admin Assistant · Back Office Executive · Data Entry Operator · Documentation Executive · Computer Operator · Front Office Executive

Test 03 — Education / Sanskrit Track

Sanskrit grammar, reading/writing, Hindi communication, lesson planning, classroom management, assessment, teaching methodology, educational content, worksheets, presentations, online teaching and basic educational technology.

Sanskrit Tutor · Sanskrit Teacher Assistant · Hindi/Sanskrit Tutor · Academic Coordinator · Education Content Assistant · EdTech Content Executive

Assessment Architecture

  • 70 questions per test: 50 conceptual MCQs + 20 one-word questions.
  • Domain-level cognitive/skill profile.
  • Weak-area practice recommendations.
  • Career-path mapping based on the test.
  • Candidate-specific report and PDF printing.
